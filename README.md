# C2 Adversary Simulation & Threat Detection

## 🎯 Objective:
Simulate a realistic Command and Control (C2) attack against a Windows endpoint, then use the resulting security activity to develop detection rules and dashboards for identifying suspicious behavior.

## 📊 Project Overview:
Conducted an end-to-end adversary simulation using the Mythic C2 framework against a Windows 11 endpoint. The simulation progressed through a brute-force credential attack, remote desktop access, host reconnaissance, defense evasion, and delivery of a custom C2 payload that established a live callback session. The resulting telemetry was then analyzed to identify suspicious process creation, outbound network activity, and Windows Defender tampering. Detection rules and a security dashboard were developed to provide visibility into the simulated attack activity and demonstrate how attacker behavior can be detected and investigated.

- Remote access and post-exploitation reconnaissance

## 📁 Key Deliverables:
- Documented C2 concepts, frameworks, and a multi-phase attack-chain diagram
- Deployed a Mythic C2 server via Docker on Ubuntu
- Executed a full adversary simulation: brute force → remote access → reconnaissance → defense evasion → payload delivery → live C2 callback
- Generated and deployed a custom Apollo C2 payload (`svchost-justin-apollo.exe`)
- Investigated the resulting security telemetry and performed hash-based threat intelligence analysis using VirusTotal
- Created a detection rule (`MYDFIR-Mythic-C2-Apollo-Agent-Detected`) to identify Apollo agent activity
- Built a 3-panel security dashboard (`MYDFIR-Suspicious-Activity`) covering process creation, network connections, and Windows Defender tampering

### 3. Credential Attack & Initial Access:

- Brute-forced Windows 11 administrator credentials using Hydra with a custom wordlist.
- Established remote access to the Windows endpoint using RDP.
- Performed host reconnaissance, including user, network, and group enumeration.

### 4. Payload Generation & C2 Callback Establishment:

- Generated a custom Apollo Windows agent payload with an HTTP C2 profile configured to communicate with the Mythic server.
- Delivered the payload to the target endpoint and executed it, establishing a live C2 callback session.
- Interacted with the compromised host through Mythic by executing commands and retrieving files.
- Validated C2 connectivity and remote command execution.

### 5. Detection Engineering from C2 Telemetry:

- Investigated Sysmon telemetry generated by the payload, including process creation events and file hash information.
- Performed a hash-based threat intelligence lookup using VirusTotal.
- Built and saved a detection search to identify Apollo agent activity.
- Created a corresponding detection rule (`MYDFIR-Mythic-C2-Apollo-Agent-Detected`) to provide visibility into the simulated C2 activity.

### 6. Suspicious Activity Dashboard:

- Monitored Windows Defender real-time protection tampering.
